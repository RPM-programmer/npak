# 📦 npak (Node Pack Archiver)

Быстрый кроссплатформенный бинарный архиватор на Node.js с собственным закрытым форматом контейнера **`.npak`**.

## ✨ Основные возможности

- **Собственный бинарный формат `.npak`**: двухступенчатое кодирование через закрытые частотные словари и 4-битные спецкоманды.
- **Полная поддержка Unicode**: приоритетное кодирование кириллицы, латиницы, символов кода, эмодзи и иероглифов CJK.
- **Гибридный движок сжатия**: текстовые файлы сжимаются по частотному словарю, а медиафайлы и бинарники упаковываются напрямую без раздувания.
- **Потоковая обработка**: запись на диск через буфер без переполнения оперативной памяти даже на больших папках.
- **Защита целостности**: фирменная сигнатура `NPAK` и проверка контрольной суммы `SHA-256` при распаковке.
- **Интеграция с Linux**: автоматическая установка фирменной иконки и распаковка архивов по двойному клику мышкой.

## 🚀 Установка

### Глобальная установка через npm

```bash
npm install -g npak
```

### Установка из исходников (с настройкой иконки и двойного клика в Linux)

```bash
git clone https://github.com/RPM-programmer/npak.git
cd npak
sudo node setup.js
```

_(Для Windows достаточно выполнить `node setup.js` без `sudo`)._

## 💻 Использование в терминале

### Упаковка папки или файла

```bash
npak pack ./my_project ./archive.npak
# или короткий псевдоним:
npak p ./my_project ./archive.npak
```

### Распаковка архива

```bash
npak unpack ./archive.npak ./restored_folder
# или короткий псевдоним:
npak u ./archive.npak ./restored_folder
```

### Работа со стандартным форматом `.zip`

Утилита поддерживает прозрачное делегирование задач системному архиватору для работы с `.zip`:

```bash
npak pack ./my_project ./archive.zip -f zip
npak unpack ./archive.zip ./restored_folder -f zip
```

## 🧩 Использование в коде (Node.js API)

Вы можете подключать `npak` как обычную библиотеку в своих проектах:

```javascript
const { pack, unpack } = require("npak");

// Упаковать папку или файл
pack("./source_folder", "./backup.npak");

// Распаковать архив
unpack("./backup.npak", "./output_folder");
```

---

## 🛠 Логирование ошибок

При возникновении проблем (отсутствие файла, нарушение контрольной суммы `SHA-256`, повреждение структуры) утилита выводит понятную причину на русском языке в консоль и сохраняет историю в файл `~/.npak-error.log`.
